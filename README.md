# نظام إدارة المكاتب والموظفين · أبناء فارس أبو زايد

نظام واحد لكل الفروع: الفروع، والموظفين، والصلاحيات المتسلسلة، ولاحقاً الحضور والرواتب والمراسلات وكل أقسام نظام «مخيم 2».

- `backend/`: Laravel 13 (PHP 8.2+) + MySQL/MariaDB. الـAPI تحت `/api`.
- `frontend/`: React + TypeScript (Vite)، بنفس شكل نظام مخيم 2.
- `docs/01-database-design.md`: مخطط قاعدة البيانات والقرارات.

## التشغيل محلياً

```bash
# الباك إند
cd backend
cp .env.example .env        # عدّل DB_DATABASE / DB_USERNAME / DB_PASSWORD
composer install
php artisan key:generate
php artisan migrate
php artisan serve           # http://127.0.0.1:8000

# الواجهة (بشاشة ثانية)
cd frontend
npm install
npm run dev                 # http://localhost:5173 (بتحوّل /api للباك إند)
```

أول ما تفتح الموقع على قاعدة فاضية بتطلع شاشة «تجهيز النظام»، وفيها بتعمل حساب السوبر أدمن.
أو من السيرفر: `php artisan app:super-admin <اسم-المستخدم> --name="الاسم"`. هالأمر كمان بيرجّع الدخول لو انقفل الحساب.

## الاختبارات

```bash
cd backend && php artisan test     # بتشتغل على قاعدة af_office_test (MariaDB)
cd frontend && npx tsc --noEmit
```

## المرحلة 1 (هلأ)
- الدخول باسم مستخدم ورمز. بعد 5 محاولات غلط الحساب بيتقفل 15 دقيقة.
- الحساب الجديد بياخد رمز مؤقت، وصاحبه لازم يغيّره أول ما يدخل.
- الفروع، وأقسام كل فرع (فتح وتسكير)، ودوامات الفرع (الجمعة دوام)، والعطل، والأقسام.
- المستخدمين حسب الفرع والمستوى. ما حدا بيدير حساب بمستواه أو أعلى منه.
- شاشة الصلاحيات: لكل دور، واستثناءات لشخص، بثلاث مستويات (إله بس / فرعه / كل الفروع).
- سجل الحركات لكل تعديل حساس.
